# 08. Reportes e indicadores

## Filtros compartidos

- Fecha: día, semana, mes y rango personalizado.
- Línea: PVC / manteles / consolidado.
- Producto/SKU.
- Modalidad: PVC por metro, rollo completo o mantel por unidad.
- Proveedor para compras.
- Estado de venta/pago cuando aplique.

## Reportes

| Reporte | Datos principales |
|---|---|
| Ventas | Número de ventas, ventas brutas/netas, descuentos, devoluciones y cobros. |
| Ganancias | Ventas netas, costo de ventas y ganancia bruta. |
| Resultado operativo | Ganancia bruta menos gastos operativos. |
| Productos vendidos | Cantidad de metros, rollos completos y manteles vendidos. |
| Rentabilidad por SKU | Ventas, costo de ventas, ganancia y margen por variante. |
| Rentabilidad por rollo | Costo individual, metros vendidos, ingresos, costo consumido y remanente. |
| Compras | Cantidad, costo, proveedor, fecha y gastos asociados. |
| Inventario PVC | Rollos íntegros, rollos cortados, metros disponibles y valor estimado. |
| Inventario manteles | Unidades disponibles y valor estimado. |
| Merma/daños | Metros/unidades dañados, motivos y costo estimado. |
| Movimientos | Entradas, salidas, cortes, devoluciones, ajustes y anulaciones. |
| Cuentas pendientes | Total vendido, total cobrado y saldo pendiente. |
| Gastos | Gastos por categoría y período. |

## Definiciones

- **Ventas netas:** importe de ventas confirmadas menos descuentos y devoluciones aplicables.
- **Costo de ventas:** costo histórico asignado a las unidades/metros vendidos.
- **Ganancia bruta:** ventas netas menos costo de ventas.
- **Resultado neto operativo:** ganancia bruta menos gastos operativos registrados.
- **Cobros recibidos:** pagos efectivamente registrados; no son equivalentes al total de ventas si existen saldos pendientes.
- **Inversión en compras:** importe de compras de inventario del período. Se informa por separado; no se resta íntegramente del resultado si esos productos siguen en stock.
- **Valor de inventario:** costo asignado a existencias todavía disponibles, de acuerdo con la política de costeo.

## Exportación

La exportación Excel/PDF está prevista. Los archivos deben respetar los mismos filtros y período del reporte visual, incluir fecha de generación, moneda y unidades, y no presentar valores de ejemplo como cifras reales.

## Precauciones

- Los reportes financieros deben usar movimientos confirmados, no borradores de IA.
- Excluir ventas anuladas o compensarlas correctamente mediante devoluciones/reversiones.
- Diferenciar facturación/venta, cobro recibido y saldo por cobrar.
- La política de costeo de manteles y el tratamiento contable/fiscal deben aprobarse antes de considerar los reportes como estados contables formales.
